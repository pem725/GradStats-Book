# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A **Quarto book** — an open, freely-editable graduate statistics textbook for the social and behavioral sciences (working title in `_quarto.yml`: "Statistics by Us for You"). The "source" is a set of `.qmd` (Quarto Markdown) chapter files that interleave English prose with executable **R** code chunks. There is no application to run and no test suite; the deliverable is the rendered HTML book in `_book/`.

## Build & preview

```sh
quarto preview      # live-reloading local server; use this while editing
quarto render       # full build of the whole book into _book/
quarto render 02-distributions.qmd   # render a single chapter (faster feedback)
```

Rendering **executes every R code chunk**. A chapter can therefore break the build through a runtime R error (missing package, bad object) — not just a Markdown mistake. When a render fails, read the R error in Quarto's output, not just the Markdown.

Requires: `quarto` (1.6.x), `R` with `knitr`, and the packages a chapter loads (currently `ggplot2`, `plotly`; add more as chapters grow). Install missing R packages with `install.packages("<pkg>")` in R before rendering.

## Structure

- **Chapter order and book metadata live in `_quarto.yml`** (`book.chapters`), NOT in filename order. A new `.qmd` file is invisible to the book until it is added to that list. Chapters are grouped into `part:` sections ("The Basics", "Making Inferences with Data", "Checking Our Data", "Using Models").
- Front matter: `index.qmd` (welcome/license), `preface.qmd`, `author.qmd`, `intro.qmd`. Numbered files `02-`…`17-` are the body chapters; `references.qmd` closes the book.
- `_book/` is generated output — do not hand-edit; it is regenerated by `quarto render`.
- `img/` holds figures (e.g. the cover `img/MRES2wbg.png`).

## Bibliography

- Two BibTeX files, both referenced from `_quarto.yml`: `statbook.bib` (hand-maintained sources) and `packages.bib` (**auto-generated** — do not hand-edit).
- `packages.bib` is regenerated on render by the `knitr::write_bib(...)` chunk in `index.qmd`. To add a package citation, load the package in a chapter and let that chunk regenerate the entry.
- Cite in prose with Quarto/pandoc syntax, e.g. `@McKnight2007`; `link-citations` and `apalike` style are set in `_quarto.yml`.

## Conventions & current state

- **Work in progress.** Many chapters are intentionally stubs — `17-basicANOVA.qmd` is empty, and several files contain only headers or literal `foo`/`bar`/`baz` placeholders inside `::: {.callout-important}` blocks. This is expected; do not treat placeholder content as a bug to "fix" unless asked to write that section.
- **Voice matters.** The prose is deliberately informal, personal, and opinionated ("Read, play, and learn"; first-person asides marked `(PEM)`). Match that tone when drafting or editing prose — do not sanitize it into neutral textbook language.
- R chunks are teaching artifacts: keep them short, self-contained, and heavily commented so a student can read them top to bottom. `ggplot2` is the default plotting idiom; `plotly` is used for interactive 3D (e.g. the learning-helix in `intro.qmd`).
- Key statistical concepts are introduced inside `::: {.callout-important}` fenced divs — reuse that pattern for new definitions.
- Chapter titles/headers use `.unnumbered` (`{.unnumbered}` / `{-}`) for front-matter-style sections; numbered chapters omit it.

## Git

Default branch is `main`; `repo-url` in `_quarto.yml` points at `https://github.com/pem725/GradStats-Book`. `.gitignore` excludes `.quarto/`, RStudio session files, and `_publish.yml` — but `_book/` IS currently committed, so a render can produce a large rebuilt-HTML diff. Avoid committing incidental `_book/` churn unless the published output is what you intend to update.
