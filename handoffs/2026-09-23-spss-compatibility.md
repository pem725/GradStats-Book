## Problems that IBM syntax alone will not solve

1. **No state between tabs.** The credible-interval SPSS tab at `20-beyond.qmd:568` uses `post` without creating or loading it, and the ROPE SPSS tab at `20-beyond.qmd:615-617` uses `theta` and `post` the same way. The book's custom engine starts a fresh PSPP process for each tab. IBM SPSS users running a chapter file top to bottom *may* inherit those variables, but the published book's tabs cannot. This is a data-flow failure independent of whether IBM supports `CREATE` or `TEMPORARY`.
2. **Different reported statistic.** The SPSS jackknife tab at `20-beyond.qmd:286-298` prints `STDDEV` of leave-one-out means. The R, Julia, and Python tabs report the jackknife **standard error**, which rescales that spread. IBM's `DESCRIPTIVES` documentation confirms `STDDEV` means standard deviation, not jackknife SE. [IBM DESCRIPTIVES statistics](https://www.ibm.com/docs/en/spss-statistics/30.0.0?topic=descriptives-statistics-subcommand-command). Compute the jackknife SE explicitly before claiming agreement.
3. **Estimator mismatch.** In `30-irt.qmd`, R calculates variance components from ANOVA mean squares while SPSS requests REML. The latter is a valid IBM `VARCOMP` method, but it is a different estimator. Compare like with like or explain why the results differ.
4. **Build success hides failure.** The full 42-source `quarto render` exited 0 on 2026-09-23 and built both download zips, while `_book/15-MRC.html`, `_book/20-beyond.html`, `_book/21-graphics.html`, and `_book/30-irt.html` still show raw PSPP diagnostics in **ten code-output blocks**. A search for `.sps:...: error:` finds 20 diagnostic lines because some blocks emit several errors. `_engines.R` currently does not reject failed PSPP output. Independently, `python3 review/check_pspp.py` ran all **100** executable SPSS chunks with PSPP `--syntax=compatible` and reported exactly those ten failures; no additional compatibility-mode failures appeared. [PSPP syntax option](https://www.gnu.org/software/pspp/manual/pspp.html).
